## How to See It

1. Make sure you're in the frontend directory:

   ```cmd
   cd frontend
   ```

2. Install dependencies (if not already done):

   ```cmd
   npm install
   ```

3. Start the development server:

   ```cmd
   npm start
   ```

4. Open http://localhost:3000 in your browser
